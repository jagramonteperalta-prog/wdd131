Quisqueya Viva

Site Plan - Dominican Republic

Site Name

Quisqueya Viva

This website is dedicated to showcasing the beauty, culture, and cuisine of the Dominican Republic.

Site Purpose

The purpose of this website is to provide information and inspiration for travelers interested in exploring the Dominican Republic.

Scenarios

  • What are some of the best cultural experiences to have in the Dominican Republic?
  • What are some of the must-try local dishes in the Dominican Republic?

Color Scheme

Domincan Blue - #003893

Used for header, navigation, and main headings

Domincan Red - #CE1126

Used for accents, borders, highlights, and hover effects

White - #FFFFFF

Used for background and text contrast

Typography

The typography for the Quisqueya Viva website will include a combination of headings and body text styles to ensure readability and visual hierarchy.

Segoe UI

Segoe UI will be used for headings, navigation, and body and text. Arial will be used as the fallback font if Segoe UI is not available.
